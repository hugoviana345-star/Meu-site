01 / VISÃO GERAL

Um sistema completo.

O AutoPrime foi criado para unir diferentes partes de uma aplicação em um único sistema.

O projeto utiliza Flutter Web para a interface e um backend responsável por acessar e armazenar informações no banco de dados.

Ao longo do desenvolvimento foram adicionadas funcionalidades de autenticação, perfil, administração e gerenciamento das informações.

STATUS

Projeto em evolução

Novas funcionalidades continuam sendo adicionadas conforme o projeto avança.
