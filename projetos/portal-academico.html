01 / VISÃO GERAL

Um portal para cada usuário.

O objetivo foi construir um sistema acadêmico capaz de atender diferentes tipos de usuários.

A aplicação possui áreas próprias para alunos, professores e administradores, alterando menus e funcionalidades dependendo do perfil utilizado.

Além da interface web, o sistema possui backend em Python com Flask e banco de dados SQLite para persistência das informações.

06 / BANCO DE DADOS

Dados que permanecem.

O projeto utiliza SQLite para manter as informações mesmo após o programa ser encerrado.

A API desenvolvida em Flask recebe as alterações realizadas no navegador, valida os dados e grava as informações no banco.

BACKEND

Persistência real

Alunos, professores, notas, frequência, eventos, turmas, avisos e materiais podem ser armazenados pelo sistema.
